# Limitations and data boundaries

- The packet is synthetic teaching data. It does not report real experiments, customer observations or private research.
- Valid zero, failure, missing data and a censored bound have different meanings. A censored bound is not an exact measured point, and a prediction cannot replace an observation.
- The example has one synthetic replicate. It does not support variance estimation, statistical significance or biological efficacy claims.
- The reference view is illustrative geometry. It does not establish docking, binding affinity, biological activity or validated structures for these candidates.
- Structured facts, source binding, identifiers and proposal limits are checked deterministically. Narrative screening is bounded and human review remains necessary. Passing checks is not proof that every sentence or proposed action is correct.
- Suggested follow-up actions remain proposals. The application does not execute experiments, establish a laboratory protocol or commit resources.
- The genuine recorded review demonstrates one successful runtime interaction. It does not prove continuous service availability, broad scientific accuracy or measured user benefit.
- Static playback makes no new Carbon call. New live inference needs separately permitted access. The event account was temporary and is not a durable service guarantee.
- No secret keys, account credentials or private source packets belong in public source, exports or videos. The local live endpoint accepts the frozen packet workflow rather than arbitrary private data.
- The current source package includes automated evidence, not proof of final public hosting, signed-out permissions, recorded video quality, competition submission or organizer acceptance.

The intended future evaluation is whether researchers can identify unsupported claims more reliably with the interface. No completed study, performance improvement, time savings, market traction, partnership or institutional endorsement is asserted.
